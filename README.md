# Simple Stronghold Finder

Simple Stronghold Finder is a client-side Fabric mod that estimates the location of a stronghold using the flight paths of two Eyes of Ender.

It does not need to be installed on the server.

## Usage

1. Enter the Overworld.
2. Throw an Eye of Ender.
3. Move a reasonable distance away, then throw a second Eye of Ender.
4. Wait for the two Eyes to finish travelling.
5. The estimated stronghold coordinates will appear in chat.

## Dependency
- Fabric API
